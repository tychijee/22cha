# 영문 아티클 → 한글 통합 정리 문서 변환

`Inputs/NN-slug.md` (영문 원문)을 읽어 `outputs/NN-slug_completed.md` (번역 + 핵심요약 + SNS 글감 통합본)를 만든다.
기준 샘플: `Inputs/01-mythos.md` → `outputs/01-mythos_completed.md`.

## 입출력 규칙

- 입력: `Inputs/NN-slug.md` — 영문 원문 텍스트만 포함.
- 출력: `outputs/NN-slug_completed.md` — 입력과 동일한 번호(`NN`)/slug를 그대로 이어받는다.
- 출력은 항상 UTF-8 마크다운 단일 파일.
- 사용자가 파일을 지정하지 않으면 `Inputs/` 안에서 아직 `outputs/`에 대응하는 `_completed.md`가 없는 파일을 찾아 처리 대상으로 제안한다.

## 출력 문서 템플릿 (섹션 순서·구분선 그대로 유지)

```markdown
# {발신 주체} {핵심 주제} 발표 정리

> ⚠️ 저작권 정책상 영어 원문 전체를 그대로 옮길 수 없어, 아래 "영어 원문" 섹션은
> 원문 링크와 핵심 포인트 개조식 정리로 대체했습니다. 한글 섹션 역시 문장 단위 직역이
> 아닌, 원문의 모든 내용을 빠짐없이 반영한 상세 정리본입니다.

---

## 1. 핵심 내용 요약

(3~6개 불릿. 발표/기사의 핵심 주장과 핵심 조치를 굵게 강조한 키워드 중심으로 정리)

---

## 2. SNS 포스팅 초안 (3가지 유형)

### ① 실무 밀착형 (해당 분야 실무자 대상)
### ② 산업 특화형 (관련 생태계/이해관계자 대상)
### ③ 트렌드 큐레이션형 (업계 전반 관심자 대상)

(각 유형마다: 1~2문장 도입 → 3~5개 불릿 요약 → 1문장 코멘트/의의 → `[원문 URL]` 자리표시)

---

## 3. 한글 번역본 (전체 상세 정리)

(원문의 소제목 단위로 **굵은 소제목**을 달고, 각 문단을 빠짐없이 한글로
상세 정리·의역. 문장 대 문장 직역이 아니라 원문의 모든 정보량을 보존하는
자연스러운 한글 문어체로 작성)

---

## 4. 영어 원문 안내

> 저작권 정책상 원문 전체를 그대로 게재할 수 없습니다. 아래에 SNS 포스팅 시
> 첨부할 원문 URL 자리와, 원문의 섹션별 핵심 포인트만 개조식으로 남겨둡니다.

- 원문 URL: `[여기에 원문 링크 입력]`

**Section-by-section key points (for reference only, not verbatim):**
(섹션별 1줄 요약을 영어 개조식으로 나열 — 원문 문장을 그대로 복사하지 않음)

---

*본 문서는 대화 중 제공된 원문 문서를 바탕으로 정리한 요약·번역·SNS 콘텐츠 초안입니다.*
```

## 작업 절차

1. **원문 정독 및 구조 파악** — 전체 주제와 발신 주체(회사/기관명), 소제목 단위 구조, 핵심 조치/발표 항목(보통 번호 리스트)을 식별한다.
2. **섹션 1 (핵심 내용 요약)** — 요지를 1~2문장 도입 후 핵심 조치·수치(금액, 프로그램명 등)를 불릿 3~6개로, 핵심 키워드는 `**굵게**` 강조.
3. **섹션 2 (SNS 3종)** — 독자층이 다른 3개 포스팅을 각각 "도입 문장 → 불릿 요약 → 의의 한 줄 코멘트 → `[원문 URL]`" 형식으로 작성.
   - ① 실무 밀착형: 실무에 바로 적용 가능한 기능/변경사항 중심
   - ② 산업 특화형: 특정 생태계(오픈소스, 특정 업계 등)에 미치는 영향 중심
   - ③ 트렌드 큐레이션형: 산업 전반의 흐름·시사점 중심
4. **섹션 3 (한글 번역본 상세 정리)** — 원문 소제목 블록마다 **굵은 소제목**을 달아 구조를 보존. 문장 단위 직역이 아니라 문단 전체 정보를 빠짐없이 담은 한글 문어체로 정리. 고유명사(제품명·프로그램명·회사명)는 원문 표기 유지. 수치·날짜·전문용어(CWE, 펀드명 등)는 누락 없이 반영.
5. **섹션 4 (영어 원문 안내)** — 저작권 문제로 원문 전체를 그대로 옮기지 않는다. `원문 URL` 자리표시자를 남긴다. 섹션별 핵심 포인트를 영어 개조식 문구로만 패러프레이즈(원문 문장 그대로 복사 금지).
6. **마무리** — 문서 최하단에 안내 문구(`*본 문서는 대화 중 제공된 원문 문서를 바탕으로...*`)를 추가하고 `outputs/NN-slug_completed.md`로 저장.

## 유의사항

- **저작권**: 영문 원문을 통째로 재수록하지 않는다. 영어 섹션은 링크 + 개조식 핵심 포인트로 대체한다.
- **정보 보존**: 한글 번역본은 축약이 아니라 "빠짐없이 반영한 상세 정리"여야 한다. 조치·수치·고유명사를 누락하지 않는다.
- **일관성**: 같은 고유명사(제품/프로그램명)는 문서 전체에서 동일하게 표기한다.
- **어조**: 한글 번역본은 격식 있는 발표문 어조, SNS 포스팅은 간결하고 실용적인 어조로 구분한다.
- **구조 유지**: 섹션 순서(요약 → SNS 3종 → 한글 번역본 → 영어 원문 안내)와 `---` 구분선을 그대로 따른다.
